# 🔍 Echo Journal Parser

A lightweight utility for parsing and analyzing log/journal entries generated by Echo Anticheat.

## ✨ Features

* 📜 **Log Parsing:** Quick extraction and structured presentation of raw journal entries.
* 📊 **Streamlined Analysis:** Helps review system checks and detection logs efficiently.
* ⚡ **Standalone Executable:** Ready to run with no extra external dependencies required.

## 🚀 Installation & Usage

1. Download the latest binary from the repository or [Releases](../../releases).
2. Place the executable in your working directory.
3. Run the tool via Command Prompt or terminal:

```cmd
echo-journal.exe [path_to_journal_file]
